# Family Meal Planner

A weekly dinner planner for the family. It runs as a Google Apps Script web app,
hosted by Google for free, and keeps all of its data in one Google Sheet.

- Weekly plan with meal and restaurant suggestions
- Dish library with full recipes, ratings, comments, favorites and an automatic healthy score
- Restaurant history with suggestions
- Shopping list built from the plan, grouped by store aisle, with email and print
- Works on phones and a kitchen tablet

**Setup:** see [docs/SETUP.md](docs/SETUP.md).

Developers: `npm test` runs the logic tests, `npm run build` regenerates `dist/`
(the files you paste into Apps Script).
